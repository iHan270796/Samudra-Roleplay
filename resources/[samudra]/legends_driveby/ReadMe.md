* This FiveM script allows players in the passenger seats of vehicles to lean out and shoot, enhancing drive-by scenarios. It features customizable offsets and rotations for different vehicle seats and specific vehicle configurations for optimal positioning.

## Features

* **Enhanced Drive-By Experience:** Enables players in passenger seats to lean out of the vehicle.
* **Keybind Activation:** Players can toggle drive-by mode using a configurable keybind.
* **Global Seat Settings:** Define global lean-out positions and rotations for passenger seats.
* **Vehicle-Specific Settings:** Customize lean-out positions and rotations for individual vehicle models, accommodating unique designs.
* **Command for Toggle:** Players can also use a command to activate and deactivate drive-by mode.
* **Optional Developer Commands:** Includes commands to retrieve vehicle hashes for easier configuration.

## Installation

1.  Download the script files.
2.  Place the `legends_driveby` folder into your server's `resources` directory.
3.  Add `ensure legends_driveby` to your server's `server.cfg` file to ensure the script starts.

## Configuration

All configuration is done within the `config.lua` file.
