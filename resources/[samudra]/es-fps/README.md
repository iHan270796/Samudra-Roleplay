> **Free FiveM FPS Optimization Script** - Professional performance enhancement menu with real-time monitoring and advanced graphics controls for GTA5 servers.

## 🌟 Features

### 📊 **Real-Time Performance Monitoring**
- **Live FPS Counter** with color-coded status indicators
- **CPU/GPU/RAM Usage** tracking with circular progress bars
- **Frame Time Analysis** for detailed performance metrics
- **Historical Performance Data** for optimization insights

### 🎮 **Advanced Graphics Settings**
- **Multiple Quality Presets**: Low, Medium, High, Ultra
- **Draw Distance Control** with 5 optimization levels
- **Shadow Quality Management** (Off/Low/Medium/High)
- **Reflection Settings** for visual enhancement
- **Motion Blur & Effects** toggle controls

### ⚡ **Performance Optimization**
- **Auto-Optimize Function** based on current FPS
- **Vehicle Density Control** for traffic management
- **Pedestrian Density Settings** for NPC optimization
- **Wind & Weather Effects** management
- **Post-FX Controls** for visual effects
- **Ultra Performance Mode** for low-end systems

### 🎨 **Modern UI Design**
- **Responsive Design** built with Tailwind CSS
- **Dark Theme** with modern glassmorphism effects
- **Interactive Elements** with smooth animations
- **Real-time Data Visualization** with SVG charts
- **User-friendly Controls** with keyboard shortcuts

## 📥 Installation

### **For Server Owners**

1. **Download** the latest release from [GitHub](https://github.com/your-repo/es-fps)
2. **Extract** the `es-fps` folder to your server's `resources` directory
3. **Add** to your `server.cfg`:
   ```cfg
   ensure es-fps
   ```
4. **Restart** your server

### **For Players**

The script automatically loads when you join a server with ES-FPS installed.

## 🎯 Usage

### **Keybinds (Default)**
- **F8** - Open/Close FPS Menu
- **F9** - Toggle FPS Counter
- **F10** - Quick Auto-Optimize

### **Menu Navigation**
- Use **mouse** to interact with the interface
- **ESC** to close the menu
- **Tab** to switch between Graphics and Performance tabs

### **Quick Commands**
```
/fps - Open FPS optimization menu
/fpscounter - Toggle FPS display
/optimize - Auto-optimize based on current performance
```

## 🛠️ Configuration

The script includes intelligent auto-configuration but can be customized:

### **Performance Presets**
- **Potato Mode**: Maximum FPS for very low-end systems
- **Low**: Optimized for 30+ FPS
- **Medium**: Balanced settings for 45+ FPS
- **High**: Enhanced visuals for 60+ FPS
- **Ultra**: Maximum quality for high-end systems

### **Customizable Settings**
- Draw distance: 150m - 800m
- Vehicle density: 0% - 100%
- Pedestrian density: 0% - 100%
- Shadow quality: Off/Low/Medium/High
- Reflection quality: Off/Low/Medium/High
